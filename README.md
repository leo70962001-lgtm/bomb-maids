# 炸彈女僕 BOMB MAIDS

炸彈超人玩法 × 女僕育成的點陣圖網頁遊戲。

**▶ 線上遊玩：https://leo70962001-lgtm.github.io/bomb-maids/**

## 玩法
- 在自己的房間照顧女僕：摸頭、聊天、送禮、特訓、佈置家具。
- 接下委託進入關卡，用炸彈打倒怪物、掃除灰塵，賺取報酬與金幣。
- 每打倒一個 BOSS，就有一位新女僕加入（莓果 → 蜜糖 → 雪乃 → 夜子）。
- 用金幣購買家具、甜點、強化與衣服；女僕對決最多 4 人同場。

## 操作
| 按鍵 | 動作 |
| --- | --- |
| 方向鍵 | 移動 |
| Z | 放炸彈 / 決定 |
| X | 特技 / 返回 |
| Esc | 暫停 |

房間裡也可以直接用滑鼠點女僕和家具；手機可用畫面上的按鈕操作。

## 語言
日本語（預設）・中文・English — 在標題畫面按 ←→ 切換。

## 檔案
純 HTML5 Canvas，不需要安裝：`index.html` + `js/`。所有圖像都是用程式繪製的原創點陣圖。
